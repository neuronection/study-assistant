# JSONB inventory — the payload-contract verdict per JSON/JSONB column
# (family data-model constitution §5; study plan 81 D, ADR-200).
#
# Format: `table.column :: verdict [comment]`
#   keep-open  remains JSON: a canonical content document behind a
#              `<column>_schema_version` sibling, a boundary-validated typed
#              state document, or a genuinely open payload (extension-owned,
#              LLM block payload, list of scalars). Every keep-open column has
#              a named payload type in `backend/app/domain/payloads.py`.
#   typed-out  known-shape state migrated to typed columns/table(s); the
#              column no longer exists. The row records where it went.
#
# The schema wall (`backend/tests/test_schema_contract.py`) asserts this file
# covers exactly the JSON columns the models declare, with no stale keep-open
# rows. D5 in `scripts/check-data-model.sh` consumes the same format.
