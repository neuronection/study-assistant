# contracts/data-model.lifecycle.txt — lifecycle classes (guidelines/data-model.md §7).
#
# Every mapped table declares exactly one class. The gate (D6) rejects an
# unclassified table and a stale row; `tests/test_lifecycle_inventory.py`
# proves coverage + the single-tombstone rule.
#
# record       retained with the subject/record; erased only when the subject
#              is erased (profiles, courses, documents, catalogue config)
# operational  bounded retention, pruned by policy (logs, telemetry, blobs,
#              trash snapshots)
# transient    prunable at any time (sessions, pending quiz state, jobs)
#
# Tombstones exist ONLY in `deleted_items` (operational): it is the single
# trash surface (plan 77-F snapshot restore). No other table carries
# `deleted_at`/`is_deleted` soft-delete semantics; every other delete is a
# hard delete, purge-only and cascade-complete.
