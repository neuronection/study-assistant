# Printing & PDF export

Everything in Study Assistant can be printed to PDF through your browser's or
desktop shell's native print dialog — math renders correctly because the
print views use the same KaTeX renderer as the app. No account, no cloud, no
extra software.

## How to print

1. Open the surface you want (quiz, due flashcards, an extraction, the
   planner).
2. Use its **Print** action:
   - **Quiz rows** (Practice tab → row menu): *Print paper…* for an exam-style
     paper with answer lines, *Print answer key…* for the correct answers.
   - **Flashcards** (Practice tab → Cards segment): *Print cut-out sheet*
     prints every due card as a fold-over card (question on top, answer below
     the dashed line — cut and fold).
   - **Extractions** (material reading view): the printer icon prints the
     extraction as a document with title and context cover.
   - **Planner** (workspace root → Planner tab): *Print week* prints the
     current week's plan items grouped by day.
3. The print preview opens with a **Print** button (and a **Back** button to
   return). In the dialog, choose *Save as PDF* (or a physical printer).

## Desktop vs browser

- **Browser (webapp mode)**: the print dialog is your browser's — margins,
  paper size, and *Save as PDF* all work as usual. This is the most reliable
  path for pixel-perfect PDFs.
- **Desktop app (pywebview)**: printing opens the GTK print dialog, which
  includes *Print to File* (PDF). If the PDF output ever looks wrong (e.g.
  math fonts substituted), print from webapp mode instead — the same surfaces
  are available there.

## Tips

- Answer keys are generated by the app from the same data that grades your
  answers — they always match the quiz exactly.
- Flashcard sheets print two cards per row; the dashed line is the fold line.
- The planner sheet always covers Monday–Sunday of the current week.
