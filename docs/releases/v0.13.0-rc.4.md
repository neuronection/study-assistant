# Study Assistant 0.13.0-rc.4

Fourth release candidate of the 0.13 line. Supersedes rc.3 (Windows launch fix: auth-kit 0.5.1
handles a missing `os.fchmod`). **This is a breaking release: 0.12.x data is not migrated.**

## Upgrade (required)

0.13 rebuilds the datastore schema (UUID identities, the squashed baseline). A 0.12.x database is
refused at boot with an actionable message and a `STARTUP-ERROR.txt` in the data directory; 0.12.x
backups are refused before anything is swapped.

1. Keep the 0.12.x data directory as it is — the refusal does not modify it.
2. Move it aside, or run `StudyAssistant reset --all` (`python -m studyassistant reset --all` from
   source).
3. Start 0.13 and complete onboarding. Backups made by 0.13 restore normally.

## Highlights

- **Token-aware retrieval** — offline tokenizer with real token accounting; a v2 token-window
  chunker that builds beside the v1 space, backfills, passes coverage/quality and cuts over;
  bounded live indexing progress in Settings → Indexing.
- **Retrieval operations** — spaces, provisioning, coverage, quality compare/gate, alerts, and a
  read-only observation surface (runs, spaces, quality, query health, usage).
- **Cloud calendars** — bind Google, Microsoft 365, Nextcloud, iCloud, Fastmail, CalDAV or an ICS
  feed; exam, deadline and milestone dates project as all-day events; two-way sync is opt-in;
  credentials stay in the OS keyring.
- **Connected sources & academic ingest** — arXiv/OpenAlex/Crossref discovery, `.bib`/`.ris`,
  `.ics`, markdown vaults, WebDAV/Drive/Dropbox/OneDrive/Zotero/Anki; every import lands as a
  suggestion you review.
- **Extension host** — validated manifests, bundled connectors and MCP instances; the frozen
  bundle and the Docker image now ship the family contracts and extension data.
- **PostgreSQL 16 web mode**, profiles/identity, and the 0.13 hardening round (restore safety, typed
  schema-break refusal, packaging completeness, CSP/OAuth callback, calendar sync safety).

## Known limitations

- **CalDAV recurring events** (Nextcloud/iCloud/Fastmail) can appear as a single item at the series
  start; in-window occurrence expansion is a follow-up in the 0.13 line.
- **Google/Microsoft calendar OAuth** needs deployment client ids
  (`SA_GOOGLE_CLIENT_ID` / `SA_MICROSOFT_CLIENT_ID`); CalDAV/ICS work out of the box.
- **Update badge** activates once the website version API is deployed; it stays dormant otherwise.
- **Windows** is built and smoke-tested by this tag's CI — this rc is the first verification of this
  bundle.
- **No data migration from 0.12.x** (by design; see Upgrade).

## Install

- Linux: `studyassistant_0.13.0-rc.4_amd64.deb` or `StudyAssistant-0.13.0-rc.4-x86_64.AppImage`
- Windows: `StudyAssistant-0.13.0-rc.4-windows-x64.exe`
- Docker: `ghcr.io/neuronection/study-assistant:0.13.0-rc.4`
