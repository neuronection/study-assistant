# Study Assistant 0.13.1

A patch release that corrects the self-hosted **deploy bundle**. No
application behavior change: the app image is unchanged from 0.13.0 apart
from the version metadata.

## What changed

- **The source-free deploy bundle now includes `docker/init-db.sh`.** The
  0.13.0 `study-compose-v0.13.0.tar.gz` omitted it; the corrected
  `study-compose-v0.13.1.tar.gz` ships the complete `docker/` runtime.
- The bundle also carries the compose hardening from the 0.13.1 branch:
  pinned base images (pgvector `0.8.7-pg16`, nginx `1.31.8-alpine`) and a
  wider DB healthcheck start period.
- Desktop and Docker application behavior is identical to 0.13.0.

## Upgrade

Self-hosted operators on the 0.13.0 bundle should re-deploy from the
corrected bundle (or add the missing `docker/init-db.sh` manually). Desktop
users on 0.13.0 do not need to upgrade.

## Install

- Linux: `studyassistant_0.13.1_amd64.deb` or
  `StudyAssistant-0.13.1-x86_64.AppImage`
- Windows: `StudyAssistant-0.13.1-windows-x64.exe`
- Docker: `ghcr.io/neuronection/study-assistant:0.13.1`
- Self-hosted: `study-compose-v0.13.1.tar.gz` + `manifest.json` +
  `SHA256SUMS` (image pinned by digest in the manifest)

The full change list is in `CHANGELOG.md`.
